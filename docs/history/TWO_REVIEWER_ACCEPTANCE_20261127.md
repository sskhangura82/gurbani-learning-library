# Historical source review — acceptance frozen before implementation

Owner decision, 27 November 2026: ChatGPT prepares historical claims using authentic sources; actual Claude double-checks them. Mandatory human authorship or a mandatory human review is superseded for this workflow. No human credential, approval or Claude review may be invented.

Frozen subject: PR #71 head `64fcfd10aeb0b12d6db58586f93b0844b6357684`.

1. AI-assisted authorship remains explicit. Readiness depends on source-review records from ChatGPT/OpenAI and Claude/Anthropic, with distinct identities, roles, producer/session references and referenced review artifacts. A code review is not a semantic source review.
2. Each review binds the complete draft packet, every claim statement, source metadata and a declared inspected source snapshot, plus every paragraph. Changing prose, claims, sources, locators, relationships or source observations makes previous reviews stale.
3. The initial author records precise source support claim by claim. Claude independently assesses the same claims and paragraphs. Missing, unsupported, disputed without retained qualification, incomplete or stale assessments keep the draft pending. A caller supplies the trusted reviewer identities separately from the draft.
4. The deterministic validator checks recorded evidence and declared identities. It cannot authenticate a provider from a string, prove that a reviewer read a source, or establish historical truth. Importers must verify producer/artifact provenance; model agreement is not evidence by itself.
5. Tests use synthetic people, sources and reviews. They cover changed prose reusing a claim ID, changed source snapshot, same provider/reviewer, missing assessment, unsupported claim, fabricated narrative reusing old receipts, code-review substitution and absence of actual Claude review.
6. The real Kartarpur manuscript retains current qualifiers and source limitations. It can receive only the first-stage ChatGPT inspection actually performed in this task. No actual Claude semantic review is claimed. No scripture changes, publishing, application routes, production storage or service-worker changes occur here.
7. The reviewed result is an editorial draft, with human review honestly unperformed. The source-review validator neither deploys a site nor grants release authorization. This does not add a new mandatory human gate.
