## B. Distinct permission scopes

Record affirmative permission for each independent activity. Unchecked means **not permitted**.

| Scope | Permission |
|---|---|
| Process this separately supplied audio privately for timing alignment, without training a model | ☐ Granted ☐ Denied |
| Retain a copy temporarily until a defined deletion date or withdrawal | ☐ Granted ☐ Denied |
| Keep **derived timing metadata** privately for quality review | ☐ Granted ☐ Denied |
| Publish the timestamp map without distributing the recording | ☐ Granted ☐ Denied |
| Associate the published map with the contributor's public YouTube video ID | ☐ Granted ☐ Denied |
| Publish the contributor's name, photograph, voice or original audio via our application | ☐ Granted ☐ Denied — **separate permission**, not implied |
| Share private source with a designated qualified timing reviewer | ☐ Granted ☐ Denied |
| Use any part of recording to train or fine-tune a speech model | **Not requested / Not authorized** |
| Create a synthetic copy of the contributor's voice or imitate the recitation | **Not requested / Not authorized** |

We may not submit the recording to an external model or cloud service based on an internal-analysis checkbox alone; the provider, transfer region and service retention policy must be disclosed and separately accepted if used. Running a model locally is the preferred initial privacy option if technically feasible.
