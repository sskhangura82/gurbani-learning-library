Ang locators, and their real strength
Each Ang above was verified by this reviewer against Open Granth at pinned commit 34d2a7c: unique match in the named file, with the file digest confirmed. But all 1,430 files in that corpus declare source: Shabad OS Database, and its README states the corpus is built from it. So the Ang number and the Gurmukhi share one textual lineage. Two views of one database is not corroboration.
What would make an Ang authoritative
Collation against a printed Sri Guru Granth Sahib Ji. Not done. No amount of digital checking substitutes for it, and an Ang number is never sufficient authentication on its own.
