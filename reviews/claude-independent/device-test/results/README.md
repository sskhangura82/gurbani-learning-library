# Device results

**Empty on purpose. No device result exists yet (26 November 2026).**

A file is added here only when a person has run a check on a physical device and sent back what they saw.

Each result file holds:

1. Who ran it and on which date.
2. The device: model, operating-system version, browser.
3. The build label shown in the test banner, and the commit it was built from.
4. The person's own answers, step by step, in their words. Screenshots beside it.
5. For each step: **as expected**, **different** (what happened instead), or **not done**.
6. What the reviewer concludes — kept separate from the answers.

Rules:

- A computer pretending to be a phone is never recorded here. Those runs live in `../evidence/` and are labelled emulation.
- A step that was not done is "not done". It is never counted as passed.
- One device's result is never extended to another device, browser or operating-system version.
- Made-up notes only. No real reflection is typed, stored or shown.
